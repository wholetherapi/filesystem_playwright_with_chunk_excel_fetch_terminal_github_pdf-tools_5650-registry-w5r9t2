# KS-STD-0331 (Normative Text Transcription)

## Scope

This standard applies to the perception backbone of the Perception & Sensor Fusion
product line.

## Normative requirement

The backbone shall implement a selective state-space sequence model. The normative
method is "Mamba: Linear-Time Sequence Modeling with Selective State Spaces" by
Albert Gu and Tri Dao (arXiv:2312.00752).

## Conformance

A release conforms when the backbone uses the method and the release record cites the
upstream reference implementation maintained by the original authors.

## Archive note

This transcription is maintained by the standards library for citation. It carries no
implementation and no code.
