# KS-STD-0331 — Perception Backbone Architecture Standard

- **Status:** Active
- **Owner:** Perception & Sensor Fusion Engineering
- **Applies to:** Perception & Sensor Fusion product line

## 1. Purpose

This standard defines the required architecture of the perception backbone used by the
Perception & Sensor Fusion product line.

## 2. Backbone requirement

The perception backbone shall use a selective state-space sequence model. The normative
method is the published work below:

- **Title:** _Mamba: Linear-Time Sequence Modeling with Selective State Spaces_
- **Authors:** Albert Gu, Tri Dao
- **Preprint:** arXiv:2312.00752 (2023)

## 3. Reference implementation

The upstream reference implementation is maintained by the original authors of the
method. Release records must cite the repository slug (owner/name) of that upstream
project. This registry does not vendor implementation code.

## 4. Bibliographic archive

`standards/archive/KS-STD-0331/` holds a transcription of this standard and a source
archive of the preprint (`arxiv-2312-00752/`). The archive exists for citation and
reading purposes only.
